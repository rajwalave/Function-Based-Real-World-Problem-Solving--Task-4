# Data Science Internship – February 2026  
## Assignment 5 – Function-Based Real-World Problem Solving 

## Project Overview

This assignment focuses on solving real-world industry problems using core Python programming concepts such as:

- Functions
- Conditional Logic
- Loops
- Lists and Sets
- Mathematical Operations
- Return Values

Each problem simulates a real-time system used across industries including:

- Social Media Analytics  
- Healthcare Systems  
- Agriculture Monitoring  
- Banking Systems  
- IT & System Monitoring  
- Smart Energy Billing  

## Assignment Problems Covered

### 1. Social Media – Post Engagement Analyzer
- Calculates total likes
- Classifies post as Viral or Normal
- Real-world use: Marketing dashboards & analytics tools

### 2. Healthcare – Medicine Stock Alert System
- Monitors stock levels
- Generates Low Stock Alert if required
- Real-world use: Pharmacy & hospital inventory systems

### 3. Agriculture – Rainfall Adequacy Checker
- Calculates average rainfall
- Determines adequacy level
- Real-world use: Climate monitoring & irrigation planning

### 4. Social Media – Duplicate Account Detection
- Detects duplicate usernames using sets
- Real-world use: Fraud detection & moderation systems

### 5. Healthcare – Appointment Eligibility Checker
- Checks patient eligibility based on age
- Real-world use: Hospital appointment portals

### 6. Agriculture – Premium Crop Price Filter
- Filters premium crop prices above threshold
- Real-world use: Market analytics & export pricing

### 7. System Monitoring – Application Health Checker
- Evaluates system health using error count
- Real-world use: IT operations dashboards

### 8. Banking – Daily Transaction Limit Checker
- Validates daily transaction limits
- Real-world use: Banking fraud prevention systems

### 9. E-Learning – Attendance Eligibility System
- Calculates attendance percentage
- Checks exam eligibility
- Real-world use: LMS & academic systems

### 10. Smart Electricity Bill Analyzer
- Calculates bill using slab system
- Classifies usage type
- Real-world use: Smart meter & electricity board billing systems
